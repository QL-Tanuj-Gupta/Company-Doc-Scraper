# EverTest

## Overview

EverTest is an AI-powered, no-code test automation platform for web applications. It enables teams to create, execute, and manage automated tests without writing complex automation scripts. It helps improve test coverage, reliability, and execution speed while reducing manual testing effort.

## Technologies

- React
- Tailwind CSS
- shadcn/ui
- Node.js
- Python
