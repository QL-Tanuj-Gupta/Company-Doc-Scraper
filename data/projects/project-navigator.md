# Project Navigator

## Overview

A multi-tenant SaaS platform that lets any website owner embed an AI-powered agentic chatbot into their product via a single script tag. The chatbot understands the host product, can navigate between pages, call the product's own APIs, and answer questions from a knowledge base — all on behalf of the end user.

## Technologies

- Node.js
- TypeScript
- OpenAI
- PostgreSQL
- Next.js
- RAG (Retrieval-Augmented Generation)

## Features

- Any web product can integrate the chatbot in under 10 minutes
- OpenAPI spec upload → tools auto-generated, no manual coding required
- Knowledge base upload (PDFs, URLs, docs) → semantic search powered answers
- Full conversation memory per user session
- Site owners have complete control over what the agent can and cannot do
- Multi-tenant: each site's data, tools, and conversations are fully isolated
- Production-grade: secure, observable, scalable
